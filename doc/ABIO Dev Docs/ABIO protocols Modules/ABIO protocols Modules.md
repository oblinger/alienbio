# ABIO protocols Modules
Module docs for `src/alienbio/protocols/`: the typing Protocols the chemistry substrate declares, and the check that keeps the implementations conforming.

Named with the `Modules` qualifier because the plain [ABIO protocols Module](../../ABIO%20Ref/ABIO%20API/ABIO%20protocols%20Module.md) and [ABIO Protocols](../../ABIO%20Ref/ABIO%20Protocols.md) are published pages. The package is one module of substance, `bio.py`, documented as [ABIO Bio Protocols](ABIO%20Bio%20Protocols.md); that page also carries `_conformance.py` (62 lines, read by `pyright src/` only, never executed) and `__init__.py` (the export list). There is no `report.py` here or anywhere else in the package: the test report is `alienbio/report.py` under [ABIO alienbio Modules](../ABIO%20alienbio/ABIO%20alienbio%20Modules.md), and the `infra` protocols the package docstring promises were deleted with `protocols/infra.py` in T056. The classes that implement the Protocols are under [ABIO bio](../ABIO%20bio/ABIO%20bio.md); the subsystem map with its seams is [ABIO-Infra](../../ABIO%20Architecture/ABIO-Infra.md).
