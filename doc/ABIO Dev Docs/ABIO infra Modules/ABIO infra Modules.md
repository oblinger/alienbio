# ABIO infra Modules
Module docs for `src/alienbio/infra/`: what a chemistry object is made of, how it is named and stored, how tests and generators build one in a line, and the graph algorithms the chemistry container delegates to.

Named with the `Modules` qualifier because the plain [ABIO infra](../../ABIO%20Architecture/ABIO%20infra.md) and [ABIO infra Module](../../ABIO%20Ref/ABIO%20API/ABIO%20infra%20Module.md) are published pages. Two module docs carry the same `infra` qualifier for the same reason: the bare `ABIO Entity` and `ABIO IO` are the published class pages [ABIO entity](../../ABIO%20Ref/ABIO%20Classes/ABIO%20entity.md) and [ABIO IO](../../ABIO%20Ref/ABIO%20Classes/ABIO%20IO.md), and HookAnchor matches names without regard to case. The package holds four modules: `entity.py`, the `Entity` base class, `MockDat` and the head registry, whose page also carries the package's export list (`__init__.py`); `io.py`, the `IO` prefix and reference layer over dvc-dat; `mk.py`, the `Pegboard` and its `mk` singleton; `graph_ops.py`, the `GraphView` and the four queries `ChemistryImpl` exposes. The classes built on `Entity` are under [ABIO bio](../ABIO%20bio/ABIO%20bio.md), with the makers `mk` dispatches to in [ABIO Makers](../ABIO%20bio/ABIO%20Makers.md); the declared surface they satisfy is [ABIO Bio Protocols](../ABIO%20protocols%20Modules/ABIO%20Bio%20Protocols.md); the subsystem map with its seams is [ABIO-Infra](../../ABIO%20Architecture/ABIO-Infra.md).
